# Antigravity Studio Platform (v1.0.0-RC)

Bem-vindo à Central de Comando da **Our Dreams Studio**. Esta plataforma foi projetada para unificar o ciclo de vida de produção audiovisual, desde a captura do lead até a entrega final e gestão de ativos.

## 🚀 Funcionalidades Principais (v1.0.0-RC)

### 1. 🛡️ Vigilância Proativa (Engine Alerta Vermelho)
- Monitoramento em tempo real de prazos críticos (< 48h).
- Detecção automática de estagnação de parceiros (> 72h sem update).
- Notificações centralizadas no Dash e via Morning Digest (E-mail).

### 2. 📊 Kanban Automático (CRM & Vendas)
- Gestão visual de leads com lógica de arrastar e soltar (Grab-to-Scroll).
- Fluxo de fechamento automatizado que converte leads em projetos de produção.
- Tema visual Neon-Glassmorphism otimizado para alta produtividade.

### 3. ⚙️ Motor de Revisão (Portal do Cliente)
- Interface de aprovação exclusiva para o cliente via Tokens Públicos.
- Fluxo "Ping-Pong" de revisões documentado com histórico e contador.
- Notificações automáticas para o time administrativo sobre feedbacks.

### 4. 📅 Agenda Unificada
- Visão cronológica de todos os compromissos e prazos de entrega.
- Integração de alertas diretamente no calendário.

### 5. 👥 Controle de Terceiros (Time & Roadmap)
- Gestão de custos com especialistas externos.
- Roadmaps de produção granulares com aprovação etapa por etapa.
- Dash de pagamentos pendentes e concluídos.

### 6. 📂 Asset Vault (Data Center)
- Centralização de links de entrega e arquivos de projetos.
- Segurança baseada em tokens e status de aprovação.

## 🛠️ Stack Técnica
- **Framework**: Next.js 14 (App Router)
- **Database**: Supabase (PostgreSQL + RLS)
- **Icons**: Lucide React
- **Estilização**: Vanilla CSS / Glassmorphism
- **Types**: Strict TypeScript Compliance (Core)

## 📦 Como Rodar
1. Configure as variáveis de ambiente (`.env.local`) com as chaves do Supabase.
2. `npm install`
3. `npm run dev`
